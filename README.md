# Nexora

**News, signals and intelligence for a faster world.**

Nexora is an AI-powered news intelligence platform covering business, markets, trends, entertainment and Africa. The product is designed to explain not only what happened, but why it matters and what to watch next.

## MVP

- Responsive editorial homepage
- Business, Markets, Trends and Entertainment sections
- Search and category filtering
- What's Moving trend strip
- Market/business momentum signal card
- Story-level signal scores
- "Why Nexora" intelligence positioning
- Mobile navigation

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Roadmap

1. Connect Supabase for stories, entities, sources and trend history.
2. Add RSS/news ingestion with source attribution and deduplication.
3. Add Gemini-powered summarization and "Why it matters" analysis.
4. Add market data and economic events.
5. Add automated trend/momentum scoring.
6. Add daily email, Telegram and X distribution.
7. Add authentication, saved topics and personalized intelligence feeds.
8. Add admin/source monitoring dashboard.
